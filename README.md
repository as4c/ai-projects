# AI Systems Portfolio

Three AI-focused projects covering RAG, conversational voice research, and real-time voice agents.

## Projects

- **AI-Researcher — Unified Knowledge Assistant:** Multi-source RAG over GitHub, Slack, Google Drive, and Atlassian using LangChain, OpenAI embeddings, PostgreSQL, and pgvector.
- **Enterprise-Knowledge-Assistant — AI Voice Researcher:** Twilio-based multilingual survey calls with configurable STT/LLM/TTS providers, decision-tree questionnaires, and call insights.
- **Swipe-to-Talk — Swipe-to-Talk Voice Avatars:** Django APIs and a Pipecat WebRTC voice pipeline using Deepgram, OpenRouter, and Cartesia.

See each project directory for setup instructions and detailed documentation.
